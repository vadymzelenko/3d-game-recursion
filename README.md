# РЕКУРСИЯ: ОБЪЕКТ-1988

Психологический хоррор от первого лица на three.js по книге «Рекурсия: Объект-1988».
14 ноября 1988 года, 04:12. Младший инженер ВЦ «Прибор» Алексей Морозов коснулся корпуса
установки «ОБЕРЕГ-88» — и остался жить в 640 килобайтах памяти ЭВМ «Искра-1030».

## Запуск

Игра — статический сайт на ES-модулях, ей нужен любой HTTP-сервер (из `file://` модули не грузятся):

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

three.js и шрифты (PT Serif, PT Mono, Caveat, Oswald) подгружаются из интернета. Без сети
надписи нарисуются системными шрифтами.

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | ходьба (бега и прыжков нет) |
| Мышь | взгляд |
| **E** / Enter | взаимодействие |
| **Tab** / J | тетрадь: задача акта, записи, карманы, прочитанные бумаги |
| **Esc** | пауза (громкость, чувствительность, начать заново) |

Поддерживаются геймпад и сенсорный экран. Игра сохраняется сама (localStorage), «Продолжить» — на титульном экране.

## Сюжет и устройство

Десять актов книги — это десять стадий прохождения. Акт заканчивается, когда выполнены его
условия; тогда появляется карточка следующего акта, а новая задача — в тетради.

| Акт | Где | Что нужно |
|---|---|---|
| I. Декомпиляция реальности | кв. 42, подъезд, кв. 40, кв. 41 | часы, осмотр дома, телефон, лестница-петля, журнал дежурств, ключ под ковриком, кодовый замок ящика вахты (запасной предохранитель), доска и ящик в 41-й, щиток: сначала предохранитель, потом рубильник |
| II. Информационная энтропия | кв. 20 «Библиотека» | формуляр → поиск рукописи по шифру на стеллажах → шахматный этюд: вынести чёрного короля за пределы доски |
| III. Соматический распад | кв. 30 «Лазарет» | капельница, ЭКГ, аптечка, выписка, окно |
| IV. Бюрократический кошмар | кв. 40 (бесконечная) | машинка, поиск личного дела на стеллажах, штампы УВОЛЕН → ПОСМЕРТНО, зеркало |
| V. Рациональное ядро | кв. 41 «Физик» | тетрадь физика, «ВЭФ-202» на 404 кГц → азимут 312, место +14 |
| VI. Акустическая бездна | кв. 43 «Пустота» | перфоленты, «Маяк-205» ровно три раза → 19880414, наушники, обрывок |
| VII. Диссоциация | кв. 44 «Отражение» (дверь в торце площадки) | силуэт, трюмо — три взгляда, записки на сиденье и на диване |
| VIII. Пограничная зона | ЭВМ, кв. 50 | `connect node_1988_clone://local_session_021`, звёздная карта, журнал, балкон, телескоп 312/+14 |
| IX. Прорыв четвёртой стены | ЭВМ, щиток, **реальный браузер** | `CONNECT /DEV/RADIO_VEF 404.00`, дамп отчёта, чертёж со «внешнего» сайта, перемычка N–3, досье (пароль 19880414), вызов Никитина |
| X. Терминальный кризис | ЭВМ | `shutdown.sys`: 1 — рекурсивный виток, 2 — обрыв, 3 — передача (секретный) |

Номер квартиры начинается с номера этажа: 20-е — 2-й этаж, 40–44 — 4-й (дом героя), 50-е — 5-й.

«Смерть — это интерфейс»: четвёртое включение магнитофона, четвёртый взгляд в зеркало,
удар током на щитке или слишком долгое наблюдение в телескоп возвращают на кровать
в 04:12 — с сохранением всего найденного.

### Терминал «Искра-1030»

Полноэкранный АДОС 3.20: `help, ls, cd, cat, edit, find, browser, radioctl, connect, decrypt,
netstat, ps, shutdown.sys` и др. Файловая система (`/Документы, /Мои_документы, /Система, /Архив,
/Дневники, /Письма, /Радиоперехваты, /Фото, /Сеть, /tmp, /dev`) меняется по ходу сюжета.
Без лабораторного ключа №3 — режим «ГОСТЬ». Если команда набрана в русской раскладке
(«ды» вместо «ls»), терминал сам её поправит.

### ARG: внешний архив `gost-1988.su`

Папка `arg/` — «внешний» сайт, который игра открывает в новой вкладке: Морозов не может
выйти за пределы 640 КБ, это делает игрок. Там чертёж щитка ЩЭ-3201, форум, радиоперехваты,
секретный архив (пароль 19880414) и четыре части ключа передачи для третьего финала
(`decrypt /Сеть/порт_архива.key`).

## Структура кода

```
js/
  main.js            — шрифты, титульный экран, пролог
  game.js            — мир, кадр, взаимодействие, смерть/пробуждение, финалы
  core/events.js     — шина событий (сцены, сюжет и интерфейс общаются только через неё)
  core/state.js      — флаги, предметы, записи, сохранение
  core/input.js      — стек слоёв ввода (мир / окна / терминал), pointer lock
  core/story.js      — десять актов и режиссёр
  core/lights.js     — пул из 8 ламп, переезжающих к ближайшим «якорям» света
  world/             — подъезд-петля, квартиры, мебель, надписи (text.js)
  puzzles/           — щиток, шахматы, радио, магнитофон, телескоп, штампы
  terminal/          — терминал, файловая система, сеть ИСКРА-NET, тексты
  ui/                — HUD, документы, тетрадь, пауза, эффекты, финалы
  data/              — документы и каталог предметов/записей
arg/index.html       — внешний архив gost-1988.su
```

Надписи в мире — не парящие спрайты, а предметы с носителем: мел на стене (Caveat),
трафарет «5 ЭТАЖ» (Oswald), бурые чернила на наличнике, эмалевые таблички на дверях.
Документы показываются на своём носителе: тетрадный лист, машинопись, казённый бланк.
